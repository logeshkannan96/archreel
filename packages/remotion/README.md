# @archreel/remotion

The `<Archreel scene={scene} />` [Remotion](https://www.remotion.dev) component that animates an
[archreel](https://github.com/logeshkannan96/archreel) scene, for use inside your own videos.

```tsx
<Sequence from={90}>
  <Archreel scene={scene} />
</Sequence>
```

Peer dependencies: `remotion` 4, `react` and `react-dom` 18+. Remotion is not MIT; check
[its license](https://www.remotion.dev/license) for your company size. See
[Use it inside your own Remotion video](https://github.com/logeshkannan96/archreel#use-it-inside-your-own-remotion-video).
